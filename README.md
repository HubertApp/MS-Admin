# MS-Admin
Microservice d'administration

## Démarrer le micro service
```bash
docker compose up
```

### Précisions
Le broker est temporairement placé dans le docker compose mais sera plus tard généralisé dans un docker compose général afin qu'il n'y ai qu'une seule instance

Pour l'instant le .env n'est pas nécessaire les variables d'environnement de test sont dans le docker-compose
